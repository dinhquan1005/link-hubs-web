# 🚀 WebMarket Marketplace

Hệ thống mua bán giao diện web chuyên nghiệp tích hợp giải nén tự động.

## ✨ Tính năng nổi bật
- **Auth:** Đăng ký/Đăng nhập giả lập qua LocalStorage.
- **Shop:** Bộ lọc sản phẩm, tìm kiếm debounce, sắp xếp theo giá/lượt bán.
- **Seller:** Đăng bán giao diện, hỗ trợ tải file `.zip` và tự động tìm file `index.html`.
- **UI/UX:** Skeleton loading, Scroll Reveal animation, Toast notifications.

## 🛠 Cài đặt và Chạy thử
1. Clone dự án: `git clone <link-github-cua-ban>`
2. Cài đặt thư viện: `npm install`
3. Chạy server: `node server.js`
4. Truy cập: `http://localhost:3000`
